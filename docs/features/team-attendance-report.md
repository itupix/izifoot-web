# Présences — Mon équipe

The Présences tab is available within the existing DIRECTION/COACH Mon équipe flow. It reads the globally selected team and displays only the current club season. Reports use authenticated `GET /teams/:teamId/attendance-report` without a season parameter. The server resolves or creates the current season using the existing club calendar (Europe/Paris). Its season label is contextual text, with no season picker or historical fallback. The seasons catalog is not requested.

The API contract is defined in backend `docs/features/team-attendance-report.md`. All percentages, totals, monthly boundaries and player/session statuses are server values. The UI does not derive presence from intent or recompute rates. Null rates render —. Present/(present+absent) is explained beside the summary; unrecorded observations are shown separately. Future/cancelled sessions and dates outside player eligibility are distinct textual statuses. Historical roster limitations follow the backend contract.

Par mois defaults to the current Paris month when available, otherwise the latest month containing training. The month view is a table: French alphabetical player rows, chronological date/time columns, pinned names and horizontal scrolling within the table on mobile. Cells show server status only: green present dot, red absent dot, grey NOT_APPLICABLE dot, hollow unrecorded circle, future clock and cancelled dash. A legend and full player/date/status labels support assistive technology. Monthly player percentages come directly from server summaries. Grey eligibility uses known creation/deactivation dates; transfer/reactivation history cannot be reconstructed. Par joueur supports name search and explicit selection, then season/month totals and dated statuses. Only current active roster players are returned by the server and included in all summaries; inactive players are excluded. An empty roster shows “Aucun joueur dans l’effectif actuel.” without player/session detail. The player view keeps its stacked details; the month table scrolls independently without widening the page. Loading, retry, no team/roster/training/player states are explicit. Team remount and request cleanup prevent old reports from appearing after team changes or retries.

Validation: `npm test` (53 tests, including null/zero distinctions and Paris month boundaries). Production build succeeds after the separately documented baseline `scopeRevision` correction.

Manual checks: switch teams during slow requests; inspect a month with cancelled/future/unrecorded sessions; verify inactive players are absent, including from totals; verify an empty current roster; verify ratios match backend; verify narrow viewport layout and error retry. Browser rendering still requires a live authenticated session.
